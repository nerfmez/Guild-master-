# วิดีโอตัวอย่าง Guild Master

ทุกอย่างที่ใช้ทำวิดีโอตัวอย่าง (trailer) อยู่ในโฟลเดอร์นี้ ห้องแชทไหนก็ทำต่อได้ ไม่ต้องพึ่งไฟล์ในเครื่องเดิม

## สถานะล่าสุด (v3)

ความยาว 43.6 วินาที ขนาด 1280×720 ที่ 30 fps

| ลำดับ | ฉาก | ที่มา | ซับไตเติล |
|---|---|---|---|
| 1 | เปิดตัว: มองไกลเห็นทั้งแมพ แล้วซูมเข้าหาเมือง | ถ่ายใหม่ | โลกรอบหมู่บ้าน |
| 2 | เมือง: แพนผ่านหมู่บ้าน (ผังจริงของเกม) | ถ่ายใหม่ | เมืองที่มีชีวิต |
| 3 | ในกิลด์: ภาพกว้าง แล้วภาพใกล้ แบ่งโซนชัดเจน | ถ่ายใหม่ | กิลด์ของคุณ |
| 4 | ล่ามอน: หุบผาลมแดง → เนินผลึก → ทุ่งใบชา แล้วถอยกล้องไกล | ถ่ายใหม่ | ออกล่าตามเขตต่างๆ |
| 5 | งานประลองยุทธ | ใช้ซ้ำจาก v2 (`assets/v2-tournament.mp4`) | งานเทศกาล |
| 6 | เทศกาลโคมลอยกลางคืน (แสงกลางคืนแบบใหม่) | ถ่ายใหม่ | เทศกาลโคมลอย |
| 7 | โลโก้ GUILD MASTER | ใช้ซ้ำจาก v2 (`assets/v2-logo.mp4`) | – |

เพลงใช้ของ v2 (`assets/music.m4a`)

สิ่งที่แก้ใน v3 ตามที่ผู้เล่นติ v2 มา:
- **เมือง:** ใช้ผังหมู่บ้านจริงของเกม บ้านไม่เบียดกัน
- **ในกิลด์:** ขยายอาคารเป็นขั้น 3 (14×12) แล้วจัดโซน
  - มุมหลังซ้าย: บาร์ เตาครัว และโต๊ะอาหาร
  - มุมหลังขวา: ชั้นหนังสือและโต๊ะน้ำชา
  - ฝั่งขวา: หุ่นฝึก
  - ฝั่งซ้าย: เตียงพยาบาล
  - ตรงทางเข้า: โต๊ะต้อนรับ กระดานคำร้อง และโต๊ะจับกลุ่มปาร์ตี้
- **ล่ามอน:** เดิมเกมส่งนักผจญภัย 22 คนไปเขตเดียวจนดูเป็นก้อน ตอนนี้กระจายเป็นทีมละ 2–3 คนใน 6 เขต แล้วรอจังหวะที่ทีมเข้าตีมอนจริงก่อนเริ่มถ่าย
- **ซูมไกล:** มีช็อตไกลทั้งตอนเปิดและตอนท้ายฉากล่า
- **โคมลอย:** แก้ในเกม (`src/world.js`) ให้โคมอยู่เหนือชั้นความมืดและมีแสงเรืองสีส้ม

## โครงสร้าง

```
trailer/
  assets/   ไฟล์ที่ commit แล้ว
    save-day.json       เซฟกลางวัน: แรงค์ B กิลด์จัดโซนแล้ว และทีมล่ากระจายหลายเขต
    save-night.json     เซฟกลางคืน: เปิดเทศกาลโคมลอยไว้แล้ว
    v2-tournament.mp4   ฉากประลองจาก v2
    v2-logo.mp4         โลโก้ตอนจบจาก v2
    music.m4a           เพลงจาก v2
  scripts/
    lib.mjs             เปิดเกมใน Chromium และควบคุมนาฬิกาเอง ถ่ายทีละเฟรมที่ 30 fps ได้ลื่นแม้เครื่องช้า
    mksave.mjs          จำลองเกม 3 ชั่วโมง → work/save.json
    layout.mjs          ขยายกิลด์และจัดโซนเฟอร์นิเจอร์ → work/save2.json
    spread.mjs          กระจายทีมล่าไปหลายเขต → assets/save-day.json
    night.mjs           สร้างเวทีแล้วเริ่มเทศกาลโคมตอน 20:00 → assets/save-night.json
    shots_day.mjs       ถ่ายฉาก reveal, town, guild1, guild2
    shots_hunt.mjs      ถ่ายฉาก hunt1–3 (รอจนทีมเข้าตีมอนจริง)
    shots_night.mjs     ถ่ายฉาก night (รอจนถึงช่วงปล่อยโคม)
    caption.py          ใส่ซับไตเติลลงบนเฟรม
    join.py             รวมทุกฉาก ใส่ crossfade และเพลง
  work/     ไฟล์ชั่วคราว ไม่ commit
```

## วิธีสร้างวิดีโอใหม่

ทำทั้งหมดในโฟลเดอร์ `trailer/` ต้องมี Node 22, Playwright, Chromium, ffmpeg และ Python ที่มี Pillow (ต้องรองรับ raqm สำหรับสระไทย)

```bash
cd ..  && npm run export && cd trailer     # สร้าง play.html จากโค้ดล่าสุด
# ถ้าไม่เปลี่ยนเซฟ ข้ามขั้นนี้ได้ (assets/save-*.json ใช้ได้เลย)
# node scripts/mksave.mjs 10800 && node scripts/layout.mjs && node scripts/spread.mjs && node scripts/night.mjs
node scripts/shots_day.mjs        # ใส่ชื่อช็อตเพื่อถ่ายบางฉาก เช่น: node scripts/shots_day.mjs guild1,guild2
node scripts/shots_hunt.mjs
node scripts/shots_night.mjs
python3 scripts/caption.py
python3 scripts/join.py           # → work/guild-master-trailer.mp4 และ -small.mp4 (ไม่เกิน 30 MB สำหรับส่งในแชท)
```

ตัวแปรสภาพแวดล้อม (ไม่บังคับ): `PLAYWRIGHT_MODULE` และ `BROWSER_EXECUTABLE`

**เวลาที่ใช้:** เกมใช้เวลาโหลดใน Chromium แบบ headless ประมาณ 75 วินาที หลังโหลดเสร็จถ่ายได้ประมาณ 6 เฟรมต่อวินาที

## เคล็ดลับ

- **ควบคุมเวลา:** `lib.mjs` แทนที่ `requestAnimationFrame` และ `performance.now` ของเกมด้วยนาฬิกาเสมือน แล้วสั่ง `__vt.step(ms)` ทีละเฟรม
  - ห้ามใช้ `page.clock` ของ Playwright เพราะจะทำให้ถ่ายภาพช้าลงเป็นนาที
- **กล้อง:** ฟังก์ชัน `cam(t)` คืนพิกัดกริด `{x,y,z}` ตามเวลา `t` (0–1)
  - เมืองอยู่แถว y≈22, กิลด์อยู่ที่ (12,10), ทุ่งใบชา (-32,20), ป่าหมอก (0,-44), หุบผาลมแดง (94,25)
- **ภาพเบลอตอนย้ายกล้องไกล:** แผนที่ส่วนนั้นยังโหลดไม่ทัน ให้เรียก `warm(1500)` ก่อนเริ่มถ่าย
- **จังหวะปล่อยโคม:** เกมปล่อยโคมเมื่อเหลือเวลาเทศกาล 14 วินาที (`festivals.js`) สคริปต์จึงรอ 72.5 วินาที (เวลาในเกม) ก่อนเริ่มถ่าย
