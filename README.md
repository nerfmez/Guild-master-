# Little Leaf Guild — กิลด์ใบอ่อน

เกมบริหารกิลด์นักผจญภัยพิกเซลโทน cozy anime สำหรับเว็บ กิลด์อยู่บนพื้นดินรอบต้นไม้ ขยายห้อง รับสมาชิก จัดทีม และพาคนกลับบ้านจากการเดินทาง

## เปิดเล่น

เปิด **[play.html](play.html)** ในเบราว์เซอร์ได้โดยตรง ไฟล์นี้รวมโค้ด ภาพที่วาดในเกม และฟอนต์ไทยไว้แล้ว ไม่โหลดทรัพยากรภายนอก บางแอปเปิดไฟล์ HTML เป็นตัวอย่างเอกสาร หากไม่เห็นเกม ให้เปิดด้วยเบราว์เซอร์ หรือใช้วิธีรันเว็บด้านล่าง

```bash
npm start
```

เปิด `http://localhost:5173` ใช้ Node.js 20 ขึ้นไป ไม่ต้องติดตั้ง runtime dependencies

## ระบบที่เล่นได้ในเวอร์ชันแรก

- สมาชิกเริ่มต้น 4 คน ตัวละครทั้งหมด 12 คน รับได้ตามความจุห้องพัก
- อาชีพหลัก 4 สาย มีสายเชี่ยวชาญ 8 แบบ อุปกรณ์คนละ 2 ช่อง
- คำร้อง 9 แบบใน 3 พื้นที่ กิลด์ F → A พร้อมบทสุดท้ายและเล่นต่อ
- ทีมละ 3 คน เริ่มหนึ่งทีม สร้างห้องวางแผนเมื่อระดับ E เพื่อส่งสองทีม
- พลังงาน ขวัญ อาการบาดเจ็บ คิวฝึก/พัก/รักษา และความไว้ใจระหว่างสมาชิก
- ห้อง 10 ประเภท อัปเกรด 3 ระดับ ย้าย/รื้อ/ขยายที่ดิน 2 ครั้ง พร้อมตรวจทางเดิน
- คราฟต์อุปกรณ์ 10 แบบ กิจกรรมน้ำชา/มื้อเลี้ยง และบัญชีรายรับรายจ่าย
- เหตุการณ์ในภารกิจสำคัญ เลือกแนวทางเดินทาง ดูฉากต่อสู้อัตโนมัติ หรือกลับไปบริหารกิลด์
- เวลา ×1 / ×2 / ×4 และหยุดเวลา เกมหยุดจำลองขณะอยู่เบื้องหลัง
- บันทึกอัตโนมัติ สำรองเซฟ นำเข้า/ส่งออก JSON และตรวจข้อมูลเสียหาย
- เมาส์และสัมผัส เลื่อนฉาก/ซูม/เลือกห้องและสมาชิก

การต่อสู้เป็นการจำลองตามพลังทีม บทบาท อุปกรณ์ สภาพคน และการตัดสินใจ ไม่ใช่ระบบบังคับตัวละครต่อสู้เอง

## การควบคุม

เลือกคำร้อง → เลือกสมาชิกให้ครบ 3 คน → เลือกแนวทาง → ส่งทีม ช่วงรอจัดตารางคนที่อยู่บ้าน คราฟต์อุปกรณ์ หรือต่อเติมกิลด์ได้ กดการ์ดทีมที่ออกเดินทางเพื่อดูการต่อสู้และเหตุการณ์

ลากฉากเพื่อเลื่อน ใช้ +/−, ล้อเมาส์ หรือสองนิ้วเพื่อซูม กดห้องเพื่ออัปเกรด/ย้าย กดคนเพื่อดูรายละเอียด `Space` หยุดเวลา, `1`/`2`/`4` เปลี่ยนความเร็ว, `Esc` ยกเลิกการวางห้อง

ปุ่มขวาบนเปิดการบันทึก ส่งออก/นำเข้าเซฟ เสียง และเริ่มเกมใหม่ เซฟอยู่ในเบราว์เซอร์นี้ ไม่มี cloud save ควรส่งออกก่อนล้างข้อมูลหรือย้ายเครื่อง

## ตรวจและสร้างไฟล์เว็บ

```bash
npm test
npm run build
npm run export
```

`build` เตรียมเว็บหลายไฟล์ใน `dist/`; `export` สร้างไฟล์เดี่ยว `play.html` ใหม่จาก source ปัจจุบัน เมื่อแก้ source ต้องรัน export ก่อนส่งไฟล์เดี่ยวให้ผู้เล่น

ชุดตรวจ engine 12 รายการผ่าน รวมเล่นจากสมาชิกเริ่มต้นถึงตอนจบด้วยทรัพยากรที่หาได้จริง มี browser smoke test เสริม:

```bash
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs BROWSER_EXECUTABLE=/path/to/chromium node tests/ui-smoke.mjs
```

ค่าเริ่มต้นของ browser smoke เป็นพาธ runtime ของสภาพแวดล้อมผู้พัฒนา หากรันที่อื่นให้ระบุสองตัวแปรข้างต้น ตรวจการจัดทีม เหตุการณ์ รางวัล คราฟต์ อัปเกรด ย้ายห้อง เซฟ/โหลด และ viewport มือถือ 390×844

## ขอบเขตปัจจุบัน

เวอร์ชันนี้เป็นต้นแบบแคมเปญที่เล่นจบได้ เนื้อหา 9 คำร้องยังไม่ใช่เกมเต็ม 6–8 ชั่วโมง การเล่นอัตโนมัติผ่านเส้นทางตัวอย่างใช้เวลาเกมประมาณ 72 นาทีที่ ×1 หรือ 18 นาทีที่ ×4 **ก่อนรวมเวลาจัดการ UI** ตัวเลขนี้มาจากการจำลอง ไม่ใช่เวลาเล่นของผู้เล่นจริง

ยังต้องปรับสมดุลจากการเล่นจริง เพิ่มความหลากหลายของคำร้อง/บทสนทนา และขัดเกลาภาพ เสียง และการเข้าถึงก่อนเรียกว่าเกมพร้อมจำหน่าย
