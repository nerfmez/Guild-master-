# ตรวจคุณภาพฉากกิลด์มุมเฉียง

ตรวจวันที่ 10 ตุลาคม 2026 (Asia/Bangkok)

เรฟมุมมองที่ดูจริง: [Dungeon Village 2](https://kairosoft.net/game/shared/image/gm155/ss_01.png) และ [Dream House Days](https://kairosoft.net/game/shared/image/gm85/img_01.png) จาก Kairosoft ส่วน [Cainos Village](https://cainos.itch.io/pixel-art-top-down-village) ใช้เป็นเรฟวัสดุและงานพิกเซล ไม่ใช้ทรัพย์สินจากทั้งสองผู้สร้าง

เกณฑ์: พื้นเป็นกริดข้าวหลามตัด ผนังวิ่งเฉียงสองทิศ เฟอร์นิเจอร์เห็นด้านบนและด้านข้าง มุมฉายภาพตรงกับบ้านรอบกิลด์ ห้องเปิดหลังคา สีไม้/ปูนอุ่นกับหญ้าสีเสจ ฉากเต็ม viewport และหน้าจัดการเปิดจากเมนู

ฉากก่อนแก้เป็นกริดตรงและผนังหน้าตรง แม้เปิดหลังคาแล้วก็ยังไม่ตรงมุม Kairosoft จึงเปลี่ยนระบบฉายภาพเป็น 2:1 และวาดพื้น ผนัง เฟอร์นิเจอร์ บ้าน บ่อน้ำและของประกอบฉากใหม่ แยกชิ้นผนังและเครื่องเรือนเพื่อจัดลำดับการบังตามตำแหน่งบนพื้น ลดผนังด้านใกล้และเว้นช่องประตู เก็บโทนสีอ่อนตามคำสั่งผู้ใช้

ตรวจภาพจาก runtime เวอร์ชันส่ง: desktop 1440×960, เมนู/สมาชิก, phone 390×844 ทั้งฉาก เมนู และการย้ายห้อง, landscape 844×390 และเมนูภารกิจ 1440×1000 ภาพหลักใช้ ?still เพื่อหยุดตำแหน่งตัวละครให้เปรียบเทียบได้ เกมจำลองยังทำงาน

ข้อผิดพลาดที่พบและแก้: ก้อนหินทับ footprint บ้านจึงดูโผล่จากผนัง ย้ายออกและตรวจภาพซ้ำ; พิกัดคลิกหลัง pan/zoom เคยอ่านเมทริกซ์กล้องจากเฟรมก่อนหน้า เปลี่ยนเป็นการแปลงจาก focus/zoom ปัจจุบันและตรวจการเลือกห้องหลัง pan/zoom ผ่าน; ย้ายห้องที่มีสมาชิกแล้วตำแหน่งพักเดิมยังค้าง จึงย้ายตำแหน่งสมาชิกตามห้องที่ย้าย

สภาพที่เห็นหลังแก้: อาคารหลัก เฟอร์นิเจอร์ และบ้านรอบฉากใช้มุมเฉียงเดียวกัน ไม่มีกรอบบริหารถาวรบังฉาก เมนูบนมือถือไม่ล้น ตัวอย่างวางห้องเป็นรูปข้าวหลามตัดตามพื้น

ขอบเขต: ตรวจภาพนิ่งและการใช้งานจริง ไม่ได้ตรวจวิดีโอ normal-speed หรือวัด FPS บนมือถือจริง ภาพมือถือค่าเริ่มต้นซูมออกให้เห็นทั้งกิลด์ รายละเอียดเฟอร์นิเจอร์จึงเล็กกว่าบนคอม ผู้เล่นซูมและลากฉากได้ ไม่ให้เปอร์เซ็นต์ความเหมือน และยังไม่มีการยอมรับด้านศิลป์จากผู้ใช้
