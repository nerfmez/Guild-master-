# ตรวจคุณภาพภาพกิลด์เปิดหลังคา

ตรวจวันที่ 10 ตุลาคม 2026 (Asia/Bangkok)

เรฟ: https://cainos.itch.io/pixel-art-top-down-village มุมมอง 3/4 แบบ top-down และโทนหญ้ามะกอก ทางดินอุ่น ไม้/ปูน/หิน รวมการเปิดหลังคาให้เห็นห้องตามคำสั่งผู้ใช้ ภาพในเกมสร้างใหม่ ไม่ใช้ทรัพย์สิน Cainos

เกณฑ์ที่ตรวจ: ฉากเต็ม viewport, ไม่มี sidebar/กระดานบริหารถาวร, หน้าต่างเปิดผ่านเมนู, เห็นภายในและผนังจากมุมเดียวกับฉาก, ไม่มีข้อความหรือปุ่มซ้อนกัน, เมนูอ่านได้บนมือถือ และทุกหมวดหาได้โดยไม่ต้องเลื่อนแถบแท็บแนวนอน

ตรวจภาพจริง: desktop 1440×960, หน้าเมนู/สมาชิก, phone 390×844 ทั้งฉากและเมนู, landscape 844×390, หน้าภารกิจ 1440×1000 ส่วนไฟล์เดี่ยวตรวจด้วย file:// ใน Chromium

ข้อบกพร่องที่พบและแก้: CSS ของหน้าจอเก่ายังจำกัดความสูงมือถือไว้ 440px ทำให้เหลือพื้นที่ว่างด้านล่าง; ลบ media rules เดิมและตรวจ viewport ตรง 390×844 แล้ว สมาชิกเริ่มต้นเคยยืนทับกัน; กระจายตำแหน่งตามจำนวนคนในห้องและตรวจภาพซ้ำ แถบแท็บมือถือเคยต้องเลื่อนเพื่อเห็นบางหมวด; เปลี่ยนเป็นสองแถวที่แสดงทั้งเจ็ดรายการ เมนูเคยสร้าง DOM ใหม่แม้เนื้อหาไม่เปลี่ยน; ตรวจความเปลี่ยนแปลงก่อนแทน DOM เพื่อลดการรบกวน input

สภาพหลังแก้: ฉากและเมนูตรงเกณฑ์ที่สังเกตได้ในขนาดข้างต้น เปิดหลังคาเป็นค่าเริ่มต้นของห้องกิลด์ เห็นเฟอร์นิเจอร์เฉพาะหน้าที่ บ้านในหมู่บ้านยังใช้หลังคาปิดตามเรฟ ระบบบริหาร ภารกิจ และเซฟผ่านการตรวจ UI

ขอบเขต: ตรวจภาพนิ่งและลำดับสถานะการใช้งาน ไม่ได้ตรวจ normal-speed video playback หรือวัด FPS บนมือถือจริง ไม่ให้คะแนนเปอร์เซ็นต์ความเหมือน และไม่ได้รับการยอมรับด้านศิลป์จากผู้ใช้ก่อนส่ง
