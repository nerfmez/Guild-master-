# ตรวจภาพเวอร์ชันจัดวางอิสระ

ตรวจวันที่ 10 ตุลาคม 2026

เกณฑ์จากคำสั่งผู้ใช้: ถนนต่อเป็นเครือข่ายเดียว ไม่ทับสิ่งปลูกสร้าง มีรายละเอียดพื้น; เริ่มที่ดินส่วนใหญ่โล่งกับอาคารเล็กที่ต่อเติมได้; วางของแยกชิ้นและหมุนแทนต่อห้องเป็นบล็อก; ตัวละครอ่านอาชีพได้; โทน cozy และมุมเฉียงคงเดิม ฉากเต็มจอและเก็บหน้าจัดการในเมนู

ตรวจภาพจริงที่ 1440×960, 390×844, 844×390 รวมฉากเริ่ม ต่อเติม เมนู ภารกิจ และกริดย้าย/หมุน ตรวจ atlas ตัวละครสี่ทิศและของทั้งสิบประเภทสี่มุมจากฟังก์ชันวาดเดียวกับ runtime

สิ่งที่แก้หลังดูภาพ: texture พื้นหญ้าเคยติดถนนจนเกิดถนนซ้ำด้านบนบนมือถือ จึงสร้าง texture หญ้าแยก; กระจายตำแหน่งพักตัวละครตามพื้นที่เดินถึงแทนยืนเรียงแถว; ตัดพื้นทางด้วยขอบเขตถนนจริงไม่ให้รายละเอียดล้ำออก; ของที่หันหลังไม่แสดงรายละเอียดด้านหน้าทะลุ; ตรวจด้านใช้งานไม่ให้หันผ่านผนัง

ภาพหลังแก้: เห็นพื้นอาคารต่อเนื่องหลังเดียว พื้นที่ว่างรอบและภายใน; ทางเข้าต่อกับถนนหินและย้ายตามส่วนต่อเติม; บ้านรอบฉากอยู่ข้างทาง; เตียง โต๊ะ เตา และหุ่นฝึกแยกชิ้น หมุนต่างทิศ; นักรบ นักธนู นักเวท และผู้รักษามีชุด อาวุธ หมวก และทิศหน้า/ข้าง/หลังต่างกัน ปุ่มหมุนและยกเลิกอยู่เหนือแถบควบคุมบนมือถือโดยไม่ล้น

ข้อจำกัดที่ตรวจได้: รีวิวนี้ตรวจภาพนิ่งและลำดับ UI ภาพ atlas รวมท่าก้าวขา แต่ไม่ได้ตรวจวิดีโอ normal-speed หรือวัด FPS บนอุปกรณ์จริง ไม่อ้างเปอร์เซ็นต์ความเหมือนเรฟ

เรฟมุมมองที่ตรวจแล้วในงานก่อนหน้า: [Dungeon Village 2](https://kairosoft.net/game/shared/image/gm155/ss_01.png), [Dream House Days](https://kairosoft.net/game/shared/image/gm85/img_01.png), [Cainos Village](https://cainos.itch.io/pixel-art-top-down-village) งานภาพเป็นต้นฉบับของโครงการ
