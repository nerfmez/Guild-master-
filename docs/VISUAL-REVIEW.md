# ตรวจภาพห้องบนพื้นโล่ง

ตรวจวันที่ 10 ตุลาคม 2026

เกณฑ์ตามคำแก้ล่าสุด: เริ่มพื้นอาคารโล่ง แต่ผู้เล่นวางห้องเองได้ กำหนดขนาด ตำแหน่ง และทิศ แล้วขยายพื้นที่เป็นขั้น ไม่ตัดระบบห้องออก

ดูภาพ runtime จริงที่ 1440×960 และ 390×844 จากไฟล์ส่งเดียวกัน ทั้งเริ่ม 0 ห้อง กั้นห้องรอบเตียง ต่อเติมและย้ายห้อง สร้างห้องว่างบนมือถือ เมนู และตัวอย่างพื้นที่ก่อนวาง

ผลภาพ: พื้นกิลด์ต่อเนื่อง ไม่มีฐานยกแยกเป็นบล็อก ผนังห้องอยู่บนพื้นเดิมและมีช่องประตู ผนังด้านหน้าเตี้ยเพื่อเห็นของภายใน ห้องพักย้ายไปส่วนต่อเติมพร้อมเตียง พื้นที่ที่เหลือเปิดโล่งสำหรับห้องถัดไป ปุ่มหมุน/ยกเลิกบนมือถืออยู่เหนือแถบควบคุม เมนูห้องและขั้นต่อเติมอยู่ในหน้าจัดการที่เลื่อนดูได้ ไม่มี sidebar ถาวร

การแก้ระหว่างตรวจ: เส้นทางกริดครึ่งช่องเข้าไม่ถึงทางเดินแคบที่เกิดจากผนังวางทีละ ¼ ช่อง จึงใช้กริดเดิน ¼ ช่องเดียวกับการจัดวาง แล้วตรวจการย้ายห้องพร้อมของอีกครั้งผ่านทั้ง engine และ UI

ข้อจำกัด: ตรวจภาพนิ่งและการใช้งานใน browser emulation ตัวละคร/animation ไม่ได้แก้รอบนี้ ไม่มีวิดีโอ normal-speed หรือการวัด FPS บนอุปกรณ์จริง ไม่อ้างเปอร์เซ็นต์ความเหมือนเรฟ

การแก้ฉากไม่ขึ้น: เพิ่มการเลือก Canvas เมื่อ WebGL เปิดไม่ได้ และใช้ Canvas สำหรับไฟล์ content://; กู้ฉากบน canvas ใหม่เมื่อ GPU context หาย ใช้ภาพและระบบจัดวางเดิม เพิ่มสถานะเปิดฉากและปุ่มลองใหม่ แทนปล่อยฉากว่าง ดูภาพไฟล์ส่งจริงที่ 1536×864 ทั้ง WebGL/Canvas และ 390×844 แบบ Canvas หลังสร้างห้อง ภาพพื้น ผนัง ของ และตัวละครยังปรากฏครบ ไม่พบฉากขาว การตรวจนี้ไม่ยืนยันอาการบน Samsung Internet เครื่องผู้ใช้ เพราะยังไม่มีผลจากอุปกรณ์จริง

## ตรวจไฟล์ดาวน์โหลด R7

ไฟล์ส่งจริง `play-r7-2a92e1ac.html`, SHA-256 `2a92e1acd10c6723125c6e4034194d5120705bd077c312a784b9b4f7048b41a2`, 1,634,987 bytes เปลี่ยนการเริ่มเกมใน HTML จริง ไม่ใช่เปลี่ยนเฉพาะแบรนด์

ตรวจภาพ `r7-restricted-canvas.png` และ `r7-webgl.png` ที่ viewport 1536×864 DPR 2 เห็นพื้นไม้ต่อเนื่อง ผนังเปิดหลังคา ถนนหินต่อถึงบันได ลายหญ้า บ้านหลังคาฟ้า และต้นไม้ จัดวางฉากเต็มจอ HUD ไม่บังพื้นที่ใช้งานหลัก ตรวจ `r7-mobile.png` ที่ 390×844 หลังสร้างห้อง เห็นพื้นและผนังห้องใหม่พร้อมของเดิม เมนูปิดแล้วไม่เหลือกรอบถาวรและปุ่มด้านล่างแยกกัน

ตรวจ `r7-boot-error.png` จากการจำลอง Canvas เปิดไม่ได้ เห็นข้อความรุ่น R7 สาเหตุที่ตัดความยาวไว้ และปุ่มลองใหม่กลางจอ ข้อความอยู่ในกรอบและไม่ชน HUD ทดสอบการวาดจริงด้วยการนับพิกเซลพื้น/ถนนเพิ่มเติมจากการดูภาพ

ข้อจำกัด: เป็นภาพนิ่งจาก Chromium และ viewport/user agent จำลอง ไม่มีผลจาก Samsung Internet หรือ content:// บนอุปกรณ์จริง จึงยังไม่สรุปว่าแก้อาการบนเครื่องผู้ใช้แล้ว ไม่มีการวัดความลื่นหรือเปลี่ยนภาพตัวละครรอบนี้ เว็บ R6 เดิมไม่ได้อัปเดตหรือทดสอบใหม่
