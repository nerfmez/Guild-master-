# ตรวจเวอร์ชันจัดกิลด์อิสระ

ตรวจวันที่ 10 ตุลาคม 2026

ฉาก Phaser 3.90.0 / WebGL ใช้ isometric 2:1 เต็ม viewport 1440×960, 390×844 และ 844×390 เมนูปิดเมื่อเข้าเกม อาคารเริ่ม 8×6 หลังเดียว พื้นต่อเนื่อง มีจุดใช้งานหกชิ้นและพื้นที่ว่างให้ต่อเติม

`npm test` ผ่าน 16/16: แคมเปญจนจบด้วยทรัพยากรที่หาได้จริง, สองทีม, คิวดูแลคน, คราฟต์/อุปกรณ์, เซฟ/โหลด, การหมุนและย้ายทีละ ¼ ช่อง, การปฏิเสธวางทับ/ปิดประตู/หันผ่านผนัง, การต่อเติมอาคาร, ถนนและต้นไม้ที่ห้ามวางทับ, และการย้ายเซฟห้อง v1/v2 โดยรักษาความคืบหน้า

`node tests/ui-smoke.mjs` ผ่าน: จัดทีมสามคน เลือกเหตุการณ์ รับรางวัลครั้งเดียว คราฟต์/ใส่ของ ราคายืนยันอัปเกรด ปฏิเสธย้ายผิดพื้นที่ ย้ายฟรี นำเข้าเซฟพร้อมการตั้งเวลา/เสียง เดินเวลาต่อจริง โหลดโดยไม่รับรางวัลซ้ำ และมือถือไม่ล้นแนวนอน ไม่มี uncaught JavaScript errors

`node tests/visual-smoke.mjs` ตรวจการเลือกจุดใช้งานทั้งหกจากภาพจริง เลือกหลังเลื่อน/ซูม หมุนและย้ายเตียงบนมือถือด้วยปุ่มในฉาก ต่อเติมอาคาร และเปิดไฟล์เดี่ยวแบบ offline การตรวจซ้ำเฉพาะพฤติกรรมโดยไม่เขียนภาพใช้ `--verify-only`

`npm run build` และ `npm run export` ผ่าน ไฟล์เดี่ยวรวม Phaser ฟอนต์ไทย ภาพที่วาดในเกมและใบอนุญาต ไม่ใช้ HTTP/HTTPS ระหว่างเปิดแบบ file:// ไฟล์ส่งจริงเปิดทดสอบแยกตามชื่อใหม่ ผลละเอียดอยู่ใน [standalone-check.json](standalone-check.json)
