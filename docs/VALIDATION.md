# ตรวจเวอร์ชันห้องบนพื้นโล่ง

ตรวจวันที่ 10 ตุลาคม 2026

เริ่มอาคาร 8×6 ไม่มีห้องสำเร็จรูป มีจุดใช้งานเริ่มต้น 6 ชิ้น เลือกชนิดและขนาดห้องเองบนพื้นโล่ง ต่อเติมพื้นทีละขั้น 8×6 → 10×8 → 12×10 → 14×12 โดยต้องถึงกิลด์ F/E/D ตามลำดับ

`npm test` ผ่าน 19/19 รวมแคมเปญด้วยทรัพยากรที่หาได้จริง สองทีม คิวดูแล คราฟต์/อุปกรณ์ เซฟ และผังของเดิม เพิ่มการกั้นห้อง การปฏิเสธผนังทับของ/ห้องทับกัน/ประตูเข้าไม่ได้ การหมุนและย้ายพร้อมของ ปรับขนาด รื้อผนังโดยเก็บของ ต่อเติมตามขั้น/กิลด์ และย้ายเซฟ v3 เป็น v4

`node tests/rooms-smoke.mjs` ผ่านบนไฟล์ส่งจริง: เริ่ม 0 ห้อง สร้างห้อง 3×3 หมุนห้องพร้อมเตียง ต่อเติมขั้น 1 และล็อกขั้น 2 ที่กิลด์ F ย้ายห้องพร้อมเตียง สร้างห้อง 3×2 และหมุนด้วยปุ่มบนมือถือ 390×844 บันทึก/โหลดห้องสองห้อง เปิดแบบ file:// offline โดยไม่ใช้ HTTP/HTTPS และไม่มี uncaught JavaScript errors รายละเอียดอยู่ใน [rooms-check.json](rooms-check.json)

`node tests/boot-smoke.mjs` ผ่านบนไฟล์ส่งจริง: เปิดโดยปิด WebGL ใช้ Canvas ได้; เปิดแบบ WebGL แล้วทำให้ GPU context หาย สลับเป็น Canvas และรักษาความคืบหน้าครบ ทั้งสองแบบตรวจว่ามีภาพฉากจริง วางห้อง ซูม เปลี่ยน viewport เป็น 390×844 และเซฟ/โหลดได้ ไม่มี HTTP/HTTPS requests หรือ uncaught errors รายละเอียดใน [boot-check.json](boot-check.json) การตรวจนี้ใช้ Chromium ไม่ใช่ Samsung Internet หรือ content:// บนเครื่อง Android จริง

`npm run build` และ `npm run export` ผ่าน ไฟล์เดี่ยวรวม Phaser ฟอนต์ไทยและใบอนุญาต ข้อมูลไฟล์ปัจจุบันอยู่ใน [standalone-check.json](standalone-check.json)

การจัดทีม เหตุการณ์ รางวัล คราฟต์/ใส่ของ ราคายืนยันอัปเกรด และนำเข้าเซฟผ่าน browser smoke ในเวอร์ชันจัดของก่อนหน้า ไม่ได้รันทดสอบลำดับภารกิจในเบราว์เซอร์ใหม่ทั้งหมดรอบนี้; engine campaign ยังผ่านหลังเพิ่มห้อง

## การส่งผ่านเว็บ R6

หลังผู้ใช้รายงานว่าไฟล์ Canvas ยังแสดงเฉพาะของกับตัวละคร จึงส่งเกมผ่าน HTTPS ของ Sites เป็นอีกทางเลือก พร้อมรหัส R6 ที่ชื่อแท็บและแบรนด์ เกมและ renderer เท่ากับ export 3fe732e0 ทุกไบต์หลังแทนข้อความรุ่นกลับ; ไม่อ้างว่าอาการบนเครื่องผู้ใช้แก้แล้ว จนกว่าจะมีผลจากเครื่องจริง

Native deployment สำเร็จ ดู [WEB-DELIVERY.json](WEB-DELIVERY.json) ไม่ได้ตรวจ browser บน hosted Site: สภาพแวดล้อม managed ไม่มี control-browser skill จึงใช้ข้อจำกัดการตรวจตาม Sites workflow

## ไฟล์ดาวน์โหลด R7

หลังผู้ใช้รายงาน R6 ไม่ขึ้น เปลี่ยน exporter จาก gzip → DecompressionStream → Blob script → ES module เป็น classic inline scripts ทั้ง runtime และแอป โดยใช้ callback ในการแทนข้อความ HTML เพื่อรักษาโค้ด runtime ทุกอักขระ เพิ่มตัวแจ้งข้อผิดพลาดก่อนเริ่ม Phaser และแสดงเวอร์ชันกับสาเหตุถ้าเริ่มฉากไม่สำเร็จ

`npm test` ผ่าน 19/19, `npm run build` และ `npm run export` ผ่าน `node tests/standalone-compat.mjs` เปิดไฟล์ `play-r7-2a92e1ac.html` SHA-256 `2a92e1acd10c6723125c6e4034194d5120705bd077c312a784b9b4f7048b41a2` ขนาด 1,634,987 bytes ทั้ง Canvas และ WebGL โดยไม่โหลด HTTP/HTTPS

กรณี Canvas ปิด WebGL, DecompressionStream, Blob URL และ dynamic script loading ตรวจสีของพิกเซลพื้นไม้ในพื้นที่ว่างและถนนหินโดยตรง รวมจำนวนพิกเซลลายหญ้า พื้น/ผนัง และหลังคาบ้าน จึงไม่ผ่านถ้าเห็นเพียงพื้นสีเดียวกับเฟอร์นิเจอร์ สร้างห้อง 3×3 และโหลดเซฟได้ทั้งสอง renderer; viewport มือถือ 390×844 เต็มจอ จำลอง Canvas เปิดไม่ได้แล้วเห็นสาเหตุและปุ่มลองใหม่ รายละเอียด [r7-compat-check.json](r7-compat-check.json)

ตรวจภาพไฟล์เดียวกันที่ 1536×864 และ 390×844, DPR 2 และ Android user agent ใน Chromium การจำลองนี้ไม่ใช่ Samsung Internet/content:// บนแท็บเล็ตจริง สาเหตุของความล้มเหลวบนเครื่องผู้ใช้ยังไม่ได้ยืนยันจาก device console หรือผลเปิด R7 ไม่รันทดสอบ UI แคมเปญทั้งหมดซ้ำในรอบแก้ตัวโหลดนี้


## R30 คำร้องจากชาวบ้าน กระดาน และหมู่บ้าน

`npm test` ผ่าน 29/29 เพิ่มการตรวจชาวบ้านเดินมาส่งคำร้อง รับ/ปฏิเสธ/หมดความอดทน แผนค่าตอบแทนและค่านายหน้า นักผจญภัยที่ว่างหยิบงานจากกระดานเอง งานที่จองไว้และงานสำคัญรอผู้เล่น งานที่เรียกกลับกลับขึ้นกระดาน การพัฒนากิลด์แบบไอเดิลและรายได้ตอนปิดเกม (สูงสุด 2 ชั่วโมง) โครงการหมู่บ้านตามระดับ ร้านค้า/โรงตีเหล็ก และการย้ายเซฟ v4 เป็น v5

`node tests/standalone-compat.mjs` ผ่านบนไฟล์ R30 ทั้ง Canvas และ WebGL ไม่มี JavaScript error ตรวจในเบราว์เซอร์ด้วย: ชาวบ้านเดินจากบ้านเข้าโต๊ะรับคำร้อง รับงานแบบใจดีแล้วนักผจญภัยสองคนเดินไปที่กระดาน หยิบงานและทำสำเร็จ กิลด์ได้ค่านายหน้าและทีมได้ค่าจ้าง บ้าน ร้านค้า แผงตลาด และป้ายที่ดินว่างขึ้นบนแผนที่ตามระดับหมู่บ้าน

## R31 ระดับกิลด์ ผู้สมัคร และตลาดหมุนเวียน

`npm test` ผ่าน 33/33 เพิ่มการตรวจการเลื่อนระดับด้วยชื่อเสียง ผลงาน และจดหมายสอบ ชื่อเสียงลดลงตามช่องว่างระดับ ผู้สมัครที่ชื่อเสียงดึงมา (หน้าใหม่ที่สุ่มขึ้น และเงื่อนไขของคนดัง) ตลาดที่ราคาขยับตามของ ร้านเติมของจากตลาด นักผจญภัยซื้อ ใช้ และซ่อมอุปกรณ์ด้วยเงินตัวเอง และจำลองเดโม่ 5 seed ให้จบใน 45–80 นาทีเกม (ผลจริง 52–68) โดยไม่ขาดค่าดูแลและไม่มีทีมแพ้
