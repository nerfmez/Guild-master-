# ตรวจเวอร์ชันแรก

ตรวจวันที่ 9 ตุลาคม 2026

## Engine

`npm test` ผ่าน 12/12 รายการ ครอบคลุมภารกิจจริง/รางวัล/ฟื้นตัว, คำสั่งผิดไม่หักเงิน, คนซ้ำ, สร้าง/ย้าย/อัปเกรด/ขยาย, อุปกรณ์และคลัง, เงินหมดตั้งตัวได้, สองทีม, เซฟ/นำเข้าข้อมูลเสียหาย, migration, แคมเปญจากสถานะเริ่มต้นถึงจบ, เงื่อนไขกิลด์ช่วงท้าย, อาชีพ/กิจกรรม/ตัวเลือก, คิวห้องและทางเข้า

เส้นทางจำลองจบโดยไม่แก้เงินหรือเลเวล: 19 ภารกิจ, กิลด์ A, สมาชิก 6 คน, ขยาย 1 ครั้ง, สองห้องระดับ 2, เวลาเกมประมาณ 72.4 นาที ผลนี้ตรวจความเป็นไปได้ของแคมเปญ ยังไม่แทนการประเมินความสนุกหรือความยาวจากผู้เล่นจริง

## Browser

`node tests/ui-smoke.mjs` ผ่านใน Chromium ตรวจ select 1 คนยังส่งไม่ได้พร้อมเหตุผล, จัดครบสามคน, เลือกเหตุการณ์, กลับรับรางวัลครั้งเดียว, คราฟต์/ใส่อาวุธ, ห้องเฉพาะสร้างซ้ำไม่ได้, ราคายืนยันอัปเกรดตรงเงินจริง 234G/ไม้11/หิน6, ย้ายทับห้องถูกปฏิเสธ, ย้ายฟรี, เซฟ/โหลดไม่รับรางวัลซ้ำ, นำเข้าเซฟที่หยุดเวลาไว้แล้วเดินเวลาต่อพร้อมความเร็ว/เสียงตรงกับเซฟ และ viewport 390×844 ไม่มีล้นแนวนอนหรือ uncaught JS error

ตรวจเพิ่มเติมผ่าน UI: ทำลาดตระเวนจน E, ขยาย 26×20 หัก500G/ไม้18/หิน12, สร้างสวนในตำแหน่งถูกต้องหลังปฏิเสธตำแหน่งทับ

## ภาพ

ตรวจ screenshot จริง desktop/mobile หลังฟอนต์ไทยพร้อม แก้ข้อความสอนเล่นชนปุ่ม ภาพแสดงฉากวาดด้วย Canvas, ห้องและคนใน runtime รวมถึงฉากต่อสู้จาก HP/damage ของ engine ไม่ใช้ภาพจำลองเป็นพื้นหลัง

ภาพนิ่งใช้ตรวจองค์ประกอบและการอ่าน ส่วน browser smoke ตรวจการเดินเวลาและ input การตรวจนี้ยังไม่ยืนยัน FPS หรือความลื่นบนโทรศัพท์จริงทุกสเปก

## Build

`npm run build` ผ่าน สร้างเว็บ static ที่ไม่มี runtime dependency ภายนอก `npm run export` รวมเป็น `play.html` พร้อมฟอนต์และ license

เปิด `play.html` ผ่าน Chromium โดยตรง ตรวจภารกิจและตัวเลือกเหตุการณ์จนรับรางวัล พร้อม viewport 1440×960 และ 390×844 ผ่าน ไม่มี request ไปยังไฟล์หรือบริการภายนอก และไม่มี uncaught JS error ผลย่ออยู่ใน [standalone-check.json](standalone-check.json)
