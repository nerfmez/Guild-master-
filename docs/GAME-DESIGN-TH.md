# กิลด์ใบอ่อน — ระบบของเวอร์ชันแรก

ผู้เล่นบริหารบ้านของนักผจญภัยในเมืองเล็ก ภาพพิกเซลมุมเฉียง isometric 2:1 ตามเรฟ Kairosoft โทนหญ้าเขียวเสจ ทางดินอุ่น ผนังไม้และปูนตามแนววัสดุเรฟ Cainos เปิดหลังคากิลด์ให้เห็นพื้นอาคารต่อเนื่อง กิลด์อยู่พื้นดินชั้นเดียว ต้นไม้เป็นจุดจำของลานและพื้นที่ต่อเติมซื้อเพิ่มได้สองครั้ง

## วงจรหลัก

คำร้อง → เตรียมคน/อุปกรณ์ → เดินทางและต่อสู้อัตโนมัติ → ตัดสินใจในงานสำคัญ → รับเงิน/วัสดุ/ชื่อเสียง → พัก/ฝึก/คราฟต์/ต่อเติม → เปิดงานและสมาชิกใหม่

ผู้เล่นตัดสินใจว่าใครออกงาน ใครฝึก ใครพัก จะใช้งบคราฟต์ของหรือเพิ่มจุดใช้งาน และจะเดินทางแบบสมดุล รอบคอบ หรือเร่งเดินทาง ทุกการลงทุนใช้ทรัพยากรชุดเดียวกันจึงมีข้อแลกเปลี่ยน

## คำร้องจากชาวบ้านและกระดานคำร้อง (R30)

ชาวบ้านเดินออกจากบ้านในหมู่บ้าน ตามถนนมาที่ประตูกิลด์ แล้วยืนรอที่โต๊ะรับคำร้อง (ต้องมีโต๊ะรับคำร้อง และเริ่มหลังจบบทนำ) ความถี่ราว 52 วินาที หารด้วยโบนัสจากจำนวนบ้าน (+12% ต่อหลัง) และป้ายประกาศกิลด์ (+10% ต่อระดับ) ไม่ต่ำกว่า 10 วินาที ชาวบ้านรอได้ราว 80 วินาที (เสมียนเพิ่ม 25 วินาทีต่อระดับ) แล้วกลับบ้าน

กิลด์เลือก **รับขึ้นกระดาน** หรือ **ปฏิเสธ** และตั้งแผนค่าตอบแทน ค่าจ้างมาจากชาวบ้าน (ราว 2.8 เท่าของเงินรางวัลเดิมของคำร้อง ±15%) กิลด์เก็บค่านายหน้า ส่วนที่เหลือแบ่งเข้ากระเป๋าเงินของนักผจญภัยในทีม

| แผน | นักผจญภัยได้ | ความกระตือรือร้น | ทีมที่ยอมรับ | ขวัญเมื่อสำเร็จ |
|---|---|---|---|---|
| ใจดี | 80% | หยิบเร็ว (~4 วินาที) | ความพร้อม ≥ 0.85 | +6 |
| มาตรฐาน | 65% | ~8 วินาที | ≥ 0.95 | 0 |
| ประหยัด | 50% | ช้า (~18 วินาที) | ≥ 1.1 | −6 |

สมุดสัญญาเพิ่มส่วนของกิลด์ 4% ของค่าจ้างต่อระดับ งานซ้ำในวันเดียวยังจ่ายลดลงตามเดิม (70% / 35%)

เมื่อวาง **กระดานคำร้อง** นักผจญภัยที่ว่าง (อยู่บ้าน ไม่ได้ฝึก พลัง ≥ 70 บาดเจ็บ ≤ 15 และไม่ได้ปิด “หยิบงานเอง”) จะเลือกงานที่ไม่ถูกจองตามค่าจ้างที่ตัวเองได้ จัดทีมเล็กที่สุดที่รับไหว เดินมารวมตัวที่กระดาน 5 วินาที แล้วออกเดินทาง ทีมพร้อมกันยังจำกัดตามความจุ (โต๊ะวางแผน และกระดานระดับ 2/3 เพิ่มทีมละ 1)

ผู้เล่นกด **เลือกทีมเอง** เพื่อเจาะจงคน หรือ **จองไว้** ไม่ให้ใครหยิบ งานสำคัญ (ขั้นเรื่องราวและขั้นเลื่อนระดับที่ยังไม่ผ่าน) มาเป็นจดหมายจากผู้ใหญ่บ้าน ติดกระดานทันทีและจองไว้ให้ผู้เล่นเสมอ งานล้มเหลวหรือเรียกกลับจะกลับขึ้นกระดาน งานทั่วไปที่ไม่มีใครรับใน 12 นาทีเกมจะหมดอายุ

## พัฒนากิลด์แบบไอเดิลและหมู่บ้าน (R30)

การพัฒนากิลด์ถาวร ราคาเพิ่มเป็นทวีคูณทุกระดับ:

| การพัฒนา | ผล | ระดับสูงสุด |
|---|---|---|
| ป้ายประกาศกิลด์ | คำร้องมาถี่ขึ้น 10%/ระดับ | 10 |
| สมุดสัญญา | ค่านายหน้า +4% ของค่าจ้าง/ระดับ | 10 |
| เสมียนต้อนรับ | รับคำร้องทั่วไปให้อัตโนมัติด้วยแผนที่ตั้งไว้ ชาวบ้านรอนานขึ้น | 5 |
| กองทุนกิลด์ | 0.25 G/วินาที/ระดับ ทั้งตอนเล่นและตอนปิดเกม (สูงสุด 2 ชั่วโมง) | 12 |

หมู่บ้านมี 5 ระดับตามความรุ่งเรือง (0 / 250 / 700 / 1500 / 3000) ความรุ่งเรืองมาจากคำร้องที่สำเร็จ (15% ของค่าจ้าง) การรับคำร้อง เงินที่นักผจญภัยใช้ในร้านค้า การซื้อของในร้าน และการสร้างโครงการ

| โครงการ | ปลดล็อก | ผล |
|---|---|---|
| บ้านใหม่ | ระดับ 1 | เริ่ม 3 หลัง สูงสุด 10 ที่ดินว่างเพิ่มตามระดับ (2 + 2×ระดับ) คำร้องถี่ขึ้น 12%/หลัง |
| ร้านค้า | ระดับ 1 | นักผจญภัยใช้เงินส่วนตัวเมื่ออยู่บ้าน ขวัญดีขึ้น ค่าเช่าวันละ 20 G/ระดับ ซื้อไม้ หิน สมุนไพรได้ |
| ตลาดนัด | ระดับ 2 | ไม้ 3 หิน 2 สมุนไพร 2 ต่อวันต่อระดับ และค่าแผง 0.15 G/วินาที/ระดับ (นับตอนปิดเกมด้วย) |
| โรงตีเหล็ก | ระดับ 3 | ลดเงินที่ใช้คราฟต์ 10%/ระดับ |

บนแผนที่ บ้านแต่ละหลังมีที่ดินประจำ ที่ดินที่เปิดแต่ยังไม่สร้างมีป้าย “ที่ดินว่าง” บ้านที่สร้างแล้วจะเปลี่ยนเป็นบ้านหลังใหญ่ขึ้นเมื่อหมู่บ้านถึงระดับ 3 และ 5 ร้านค้า แผงตลาด (1–3 แผงตามระดับ) และโรงตีเหล็กขึ้นบนที่ดินของตัวเองเมื่อสร้าง

เซฟ v5 เก็บคำร้อง การพัฒนา หมู่บ้าน และเงินส่วนตัวของสมาชิก เซฟ v1–v4 ย้ายได้โดยเริ่มกระดานว่าง หมู่บ้าน 3 หลัง และจดหมายงานสำคัญที่ยังค้าง

## นักผจญภัย

เริ่มด้วยมิรา (นักรบ), ฟินน์ (นักธนู), ลูน (นักเวท), โนอา (ผู้รักษา) มีผู้สมัครอีกแปดคน แต่รับได้ตามชื่อเสียงและความจุเตียงพัก สูงสุดสิบสองคน

สมาชิกมีเลเวล/XP พลังพร้อมออกงาน ขวัญ และอาการบาดเจ็บ นิสัยให้ผลเล็ก ๆ จริง เช่น ฟินน์ช่วยสำรวจ ลูนฝึกเร็ว มิราบาดเจ็บน้อยลง โนอาช่วยงานรักษา คนออกงานจะทำกิจกรรมในกิลด์พร้อมกันไม่ได้

เมื่อเลเวล 5 และกิลด์ D เลือกสายเชี่ยวชาญถาวรได้:

| พื้นฐาน | สายต่อยอด | ข้อเลือก |
|---|---|---|
| นักรบ | ผู้พิทักษ์ / นักดาบ | ความอึดและป้องกัน / พลังโจมตี |
| นักธนู | พรานป่า / มือยิง | บทบาทสำรวจ / พลังโจมตี |
| นักเวท | ปราชญ์ / จอมเวทธาตุ | พลังชีวิตสูงขึ้น / เวทแรงขึ้น |
| ผู้รักษา | นักบวช / นักขับขาน | รักษา / สนับสนุน |

## การจัดวางและคอขวด

เริ่มจากที่ดินส่วนใหญ่โล่งและอาคารเล็ก 8×6 หลังเดียว มีโต๊ะรับคำร้อง เตียงพัก เตียงรักษา เตาทำอาหาร หุ่นฝึก และโต๊ะช่างเป็นของแยกชิ้น ย้ายและหมุน 90° ได้ ไม่มีห้องสำเร็จรูปตอนเริ่ม ผู้เล่นกั้นห้องเองบนพื้นโล่ง เลือกชนิดห้อง 7 แบบและขนาดกว้าง/ลึก 2–14 ช่องตามพื้นที่ที่เปิดไว้ วางและหมุนได้ทีละ ¼ ช่อง ห้องย้าย/หมุนพร้อมของภายในได้ ปรับขนาดได้เมื่อไม่ทับของและทางเข้า รื้อผนังแล้วของยังอยู่บนพื้น ห้องเป็นการจัดพื้นที่และภาพ ส่วนความจุและผลต่อระบบมาจากจุดใช้งานภายใน สมาชิกเลือกจุดใช้งานตามงานและสภาพ มีคิวจริง การอัปเกรดหรือเพิ่มจุดใช้งานช่วยความจุและความเร็ว

| จุดใช้งาน | ผลต่อระบบ |
|---|---|
| โต๊ะรับคำร้อง | เพิ่มชื่อเสียงจากงาน มีได้หนึ่งชิ้น |
| เตียงพัก | ความจุสมาชิก 4 คนต่อระดับ; พักเร็วพร้อมกัน 2 คนต่อระดับ |
| เตาทำอาหาร | ช่วยฟื้นตัวและเปิดกิจกรรมน้ำชา |
| เตียงรักษา | รักษาพร้อมกัน 2 คนต่อระดับ จัดคนเจ็บมากก่อน |
| หุ่นฝึก | ฝึกพร้อมกัน 2 คนต่อระดับ ผลัดตามเวลาที่ฝึกมา |
| โต๊ะช่าง | เปิดสูตรอุปกรณ์ตามระดับโต๊ะช่าง |
| แปลงสมุนไพร | ให้สมุนไพรรายวัน |
| ชั้นตำรา | เพิ่มประสิทธิภาพฝึกและรับมือภารกิจเวท |
| ชุดโต๊ะน้ำชา | ช่วยขวัญและเปิดมื้อเลี้ยงกิลด์ |
| โต๊ะวางแผน | เปิดทีมที่สองเมื่อถึง E มีได้หนึ่งชิ้น |

วางของทีละ ¼ ช่องและหมุนได้สี่ทิศภายในพื้นต่อเนื่อง แปลงสมุนไพรวางกลางแจ้ง อาคารต่อเติมเพิ่มกว้างและลึกทีละสองช่อง 8×6 → 10×8 → 12×10 → 14×12 ขั้น 1 ใช้กิลด์ F ขั้น 2 ใช้ E และขั้น 3 ใช้ D ต้องเปิดตามลำดับและจ่ายเงิน/ไม้/หิน โดยทางเข้าย้ายตามกึ่งกลางผนังใหม่ การซื้อที่ดิน 20×16 → 26×20 → 32×24 เป็นอีกการลงทุนหนึ่ง

ก่อนหักเงินตรวจขอบเขต ของทับ ถนน ต้นไม้ ช่องประตู และเส้นทางจากประตูถึงด้านใช้งานของทุกชิ้น ใช้ผังถนนเดียวกับภาพ ย้ายและหมุนฟรี รื้อได้วัสดุคืนบางส่วน โต๊ะรับคำร้องรื้อไม่ได้ เตียงพักรื้อไม่ได้ถ้าสมาชิกเกินความจุ และโต๊ะวางแผนรื้อไม่ได้ขณะทีมที่สองออกงาน

ตำแหน่งมีผลด้านการเข้าถึงและภาพการเดิน แต่ยังไม่ได้จำลองระยะเดินเป็นต้นทุนเวลาในการผลิต ภาพสมาชิกเคลื่อนไหวบนทางเดินไม่ใช่ระบบเดินสำรวจที่ผู้เล่นควบคุมเอง

## ภารกิจและการต่อสู้

ทีมต้องครบสามคน เริ่มส่งพร้อมกันได้หนึ่งทีม หลังสร้างโต๊ะวางแผนส่งได้สองทีมโดยไม่ใช้คนซ้ำ งาน 9 แบบในทุ่งใบชา ซากหอระฆัง และป่าหมอกจันทร์มีความต้องการบทบาทต่างกัน

- สมดุล: เวลา/พลังตามปกติ
- รอบคอบ: ช้าลง แต่รับมือดีขึ้นและใช้แรงน้อยลง
- เร่งเดินทาง: เร็วขึ้น แต่พลังรับมือลดและใช้แรงมากขึ้น

พลังทีมคำนวณจากอาชีพ เลเวล อาวุธ เครื่องราง พลังงาน ขวัญ นิสัย ห้องสนับสนุน และความไว้ใจ บทบาทป้องกัน/รักษา/สนับสนุนลดความเสียหายจริง หน้าจอแสดงความพร้อมและบทบาทที่ขาดก่อนส่ง

การต่อสู้เป็นการจำลองระหว่างเดินทาง ฉากแสดง HP ทีม/ศัตรู ระลอก และ damage จากข้อมูล engine ผลจบมาจากความพร้อมทีมและ HP ไม่ใช่การกดโจมตี คนเจ็บพักฟื้น ไม่มีความตายถาวร

งานปกติเดินตามแผนเอง เหตุการณ์เกิดในลาดตระเวนครั้งแรกและงานเรื่องราว ผู้เล่นช่วยสำรวจ เดินหน้าต่อ หรือพักเช็กอุปกรณ์ได้ กิลด์ไม่หยุดทำงานเมื่อมีเหตุการณ์ ถ้าไม่ตอบ ทีมตัดสินใจตามแผนเมื่อจบงาน

เรียกทีมกลับได้ก่อนจบ ลดความเสี่ยง แต่ไม่ได้รางวัลและเสบียงไม่คืน งานสำเร็จครั้งแรกได้รางวัลเต็ม งานซ้ำจ่ายลดลงและลดเพิ่มเติมเมื่อทำซ้ำถี่ในวันเดียว

## เศรษฐกิจและอุปกรณ์

ทรัพยากรหลักคือเงิน ไม้ หิน สมุนไพร เงินได้จากคำร้องและเงินสนับสนุนเมื่อเลื่อนกิลด์ วัสดุใช้สร้าง อัปเกรด คราฟต์ และเตรียมภารกิจ มีค่าอาหาร/ดูแลรายวันตามจำนวนคนกับห้อง สมุดแสดงรายรับรายจ่ายและรายการล่าสุด

เงินหมดไม่จบเกม งานลาดตระเวนและเก็บสมุนไพรไม่ใช้เงินเตรียมทีม สมาชิกยังพักได้ คนช่วยงานให้วัสดุปริมาณจำกัด เมื่อรายรับไม่พอดูแล ขวัญลดเล็กน้อยและมีคำแนะนำตั้งตัว

อุปกรณ์ 10 แบบ: อาวุธของสี่สายสองระดับ ริบบิ้นกิลด์ และเครื่องรางหมอกจันทร์ สมาชิกมีอาวุธกับเครื่องรางอย่างละช่อง คราฟต์ตามสูตรแน่นอน ไม่สุ่ม affix ใส่อุปกรณ์ใหม่คืนชิ้นเก่าเข้าคลัง ถอดเพื่อแบ่งให้คนอื่นได้

โต๊ะช่างในเวอร์ชันนี้คราฟต์ทันทีเมื่อมีวัตถุดิบ ยังไม่มีคิวผลิตเป็นระบบแยก

## ความสัมพันธ์และชีวิตประจำวัน

คนออกงานร่วมกันมีความไว้ใจเพิ่ม ให้โบนัสทีมที่มีเพดาน กิจกรรมน้ำชาและมื้อเลี้ยงฟื้นพลัง/ขวัญและทำให้สมาชิกที่อยู่บ้านสนิทขึ้น กิจกรรมมีค่าใช้จ่ายและ cooldown ข่าวชาวบ้าน/กำลังใจปรากฏเป็นระยะ สมาชิกมีภูมิหลังสั้น ๆ สมุดเก็บประวัติภารกิจ เลเวล ห้องใหม่ และเหตุการณ์

ยังไม่มีระบบบทสนทนาแตกแขนงทุกคู่ ความรัก หรือเป้าหมายส่วนตัวแบบสายเควสต์ยาว

## แคมเปญและปลายเกม

ชื่อเสียงและผลงานที่กำหนดเปิดระดับ F → E → D → C → B → A ชื่อเสียงอย่างเดียวข้ามงานเรื่องราวไม่ได้ ช่วงท้ายบังคับให้กิลด์เติบโตด้านการดูแลคนด้วย:

- **ช่วยทีมสำรวจ:** ต้องเปิดทางป่าหมอก มีสมาชิกอย่างน้อยหกคน มีโต๊ะวางแผน และขยายที่ดินหนึ่งครั้ง
- **รักษาหัวใจป่า:** ผ่านงานโพรง หอระฆัง และช่วยทีมสำรวจ มีสองห้องระดับสองขึ้นไป โดยเลือกชนิดห้องเอง

จบแล้วมีข้อความบทสรุป เล่นดูแลกิลด์ต่อได้ด้วยงานเดิม สมาชิกและการตกแต่งยังอยู่ ยังไม่มีโหมดหลังจบที่มีเนื้อหาใหม่ไม่สิ้นสุด

## เวลาเล่นและขอบเขต

เหมาะกับการเล่นทีละ 15–30 นาที เป้าหมายเกมเต็มเดิม 6–8 ชั่วโมงยังไม่ยืนยัน ต้นแบบนี้เส้นทางจำลองผ่านด้วยทรัพยากรจริงใช้ 19 ภารกิจ รวมเวลาเกม 4,342 วินาที หรือประมาณ 72.4 นาทีที่ ×1 / 18.1 นาทีที่ ×4 ก่อนนับเวลาตัดสินใจ UI ไม่ใช่ผล playtest กับผู้เล่นภายนอก

ความยาวต้องมาจากงานที่ต่างกัน เรื่องราว และตัวเลือกใหม่ ก่อนเพิ่มเนื้อหาจริงจะไม่ยืดเวลารอเพื่อให้ครบจำนวนชั่วโมง

ก่อนจำหน่ายยังต้องตรวจบนอุปกรณ์จริง ปรับความยากและเศรษฐกิจ เพิ่มคำร้องและเหตุการณ์ แก้ความซ้ำของฉากและเสียง และเพิ่มการเข้าถึงสำหรับผู้เล่นที่ใช้คีย์บอร์ดหรือโปรแกรมอ่านหน้าจอ

## ฉากและเมนู

ฉากหลักใช้ Phaser 3.90.0 + WebGL เมื่อเปิดได้ และ Canvas สำรองเมื่อ WebGL เปิดไม่ได้ ไฟล์ Android ผ่าน content:// ใช้ Canvas โดยตรง มีการกู้ฉากเมื่อ GPU context หาย และหยุดจำลองจนฉากพร้อม ฉากเต็ม viewport โดยไม่แบ่งพื้นที่ให้ sidebar ถาวร ปุ่มเมนูเปิดหน้าจัดการเดียว แบ่งภาพรวม คำร้อง สมาชิก ห้องและต่อเติม คราฟต์ สมุดกิลด์ และบันทึก/ตั้งค่า เลือกวางหรือย้ายห้อง/ของแล้วหน้าต่างปิดให้วางในฉากได้ทันที มีปุ่มหมุนให้ใช้บนมือถือ การจำลองดำเนินต่อเมื่อเปิดหน้าจัดการ และหยุดเมื่อเปิดคำยืนยันหรือการตั้งค่า
