# คู่มือหัวหน้ากิลด์

คุณเป็นหัวหน้ากิลด์ในหมู่บ้านเล็ก ๆ หน้าที่ของคุณไม่ใช่การสั่งใครไปไหน งานของคุณคือดูแลบ้านหลังนี้และเมืองรอบ ๆ เพื่อให้:

- นักผจญภัยอยากมาอยู่
- พวกเขาอยากรับงาน
- ทุกคนกลับบ้านอย่างปลอดภัย

## เริ่มเล่น

- **บทนำ:** พาคุณวางโต๊ะรับคำร้อง หุ่นฝึก และกระดานคำร้อง แล้วต้อนรับนักผจญภัย 4 คนแรก
- **การ์ดภารกิจมุมซ้ายบน:** บอกขั้นต่อไปเสมอ แตะเพื่อดูวิธีทำหรือให้เกมพาไปหน้าที่ต้องใช้
- **เป้าหมายใกล้ตัว:** แถบเล็กใต้การ์ดภารกิจ เช่น
  - “อีก 40 G → บาร์ระดับ 2”
  - เป้าหมายวันนี้ข้อที่ใกล้สำเร็จ
  - หน้าสมุดภาพมอนที่ใกล้ครบ
- **ความเร็วเวลา:** ปุ่มมุมซ้ายล่างหยุดเวลาหรือเปลี่ยนเป็น ×1 ×2 ×4 ได้ เกมหยุดเองเมื่อสลับไปแท็บอื่น

## กระดานคำร้อง: เครื่องมือหลักของคุณ

ชาวบ้านเดินมาส่งคำร้องที่โต๊ะ ใบคำร้องขึ้นกระดานเอง นักผจญภัยที่ว่างจะเดินมาอ่านกระดาน จับกลุ่ม แล้วออกไปทำงาน การต่อสู้เกิดขึ้นจริงบนแผนที่ แตะทีมเพื่อดูสดได้

**ค่าตอบแทน** ตั้งได้ทั้งแบบค่าเริ่มต้นและรายใบ

| แบบ | นักผจญภัยได้ | ผล |
|---|---|---|
| ใจดี | 80% | คนรีบมารับ อารมณ์ดีขึ้น กล้ารับงานเสี่ยง จึงพลาดบ่อยขึ้น |
| มาตรฐาน | 65% | สมดุล |
| ประหยัด | 50% | กิลด์ได้มากขึ้น แต่คนไม่ค่อยอยากรับ อารมณ์ลด |

**เมื่อไม่มีใครรับงาน** กระดานจะบอกเหตุผลเสมอ เช่น:

- ค่าตอบแทนต่ำไป
- ยากเกินไป
- คนไม่พอ
- กระดานเต็ม
- ขาดของที่ต้องเตรียม

แก้ได้ด้วย:

- **เพิ่มค่าหัว:** ดึงคนเก่งให้รับงานยาก
- **ระดมพล:** ใช้เมื่อมอนบุกหรือบอสโลกปรากฏตัว
- **อัปเกรดกระดานหรือวางโต๊ะจับกลุ่มปาร์ตี้:** รับงานพร้อมกันได้มากขึ้น

ส่วนแบ่งค่าจ้างคือรายได้หลักของกิลด์ ส่วนที่เหลือเข้ากระเป๋านักผจญภัย และพวกเขาเอาไปใช้จ่ายในเมืองต่อ

## นักผจญภัย

- **มาลงทะเบียนเอง:** ชื่อเสียงยิ่งสูงยิ่งมาบ่อย ไม่ต้องจ้าง
- **พักในเมือง:** ที่พักในโรงเตี๊ยมและบ้านเช่าคือเพดานจำนวนคน
- **เพดานตามระดับเมือง:** 15 · 20 · 25 · 40 · 60 คน
- **ขาประจำ:** คนที่มีชื่อราว 1 ใน 4 หน้าใหม่ทำงานสำเร็จ 5 ครั้งก็กลายเป็นขาประจำ
- **การเติบโต:** แต่ละคนมีแรงค์ F–B ของตัวเอง
  - สอบเลื่อนแรงค์ที่สนามสอบเป็นรอบ ทุกคนในรอบสอบพร้อมกัน 3 ด่าน
  - คนที่พร้อมและมีเงินสมัครเอง ใครเงินไม่พอ กิลด์ช่วยออกค่าสมัครได้
  - เลื่อนอาชีพได้ 3 ขั้นที่โรงฝึก

### สภาพ 5 ด้านและประสิทธิภาพ

| สภาพ | ถ้าแย่ | แก้ด้วย |
|---|---|---|
| 🩹 บาดแผล | ออกงานไม่ได้หรือสู้ได้ครึ่งเดียว | คลินิก เตียงรักษา ยาในร้าน |
| 💤 ความเหนื่อย | เดินช้า ตีช้า กลับเร็ว | โรงเตี๊ยม อาหารจากครัว |
| 😊 อารมณ์ | เลือกแต่งานง่าย นานไปก็ย้ายออก | บาร์ เทศกาล ค่าตอบแทนที่ยุติธรรม |
| ⚔ อุปกรณ์ | พลังตก | โรงตีเหล็ก โต๊ะช่าง |
| 🎒 เสบียง | สลบบ่อย | ร้านค้า ตลาดนัด |

ทุกด้านรวมเป็น **ประสิทธิภาพ** 60–120% ของแต่ละคน มีผลกับโอกาสสำเร็จ ความเร็ว ของที่ได้กลับมา งานยากที่กล้ารับ และความอยากอยู่ต่อ

เมนู “กิลด์” → ประสิทธิภาพ แสดงข้อมูลเหล่านี้:

- จุดคอขวดเป็นเงิน เช่น “🩹 รอรักษา 6 คน → เสียราว 120 G/วัน”
- ประเมินผลก่อนลงทุนสร้างหรืออัปเกรด
- สรุปรายวัน

## กิลด์เป็นบ้าน

**ของใช้** วางได้อิสระ หมุน ย้าย และอัปเกรดได้ 3 ระดับ:

- โต๊ะรับคำร้อง
- กระดานคำร้อง
- หุ่นฝึก
- โต๊ะช่าง
- เตาทำอาหาร
- เตียงรักษา
- บาร์
- โต๊ะอาหาร
- โต๊ะประเมินของ
- โต๊ะจับกลุ่มปาร์ตี้
- ชุดโต๊ะน้ำชา
- ชั้นตำรา
- แปลงสมุนไพร

**บาร์และโต๊ะอาหาร** นักผจญภัยที่ว่างแวะมานั่งจริงบนเก้าอี้

- คนเหนื่อยนั่งกินข้าว ต้องมีเตาทำอาหาร
- คนสดชื่นนั่งดื่ม
- ทีมที่กลับจากงานสำเร็จจะฉลองและใช้จ่ายมากขึ้น
- กิลด์ได้เงินทุกแก้วทุกจาน

**พนักงาน** 6 ตำแหน่ง แต่ละคนมีเงินเดือนรายวันและเก่งขึ้นตามวันทำงาน:

| ตำแหน่ง | ต้องมี | ช่วยอะไร |
|---|---|---|
| 🛎 พนักงานต้อนรับ | โต๊ะรับคำร้อง | คำร้องขึ้นกระดานทันที |
| 📒 นายทะเบียน | โต๊ะรับคำร้อง | คนมาลงทะเบียนถี่ขึ้น |
| 🔍 นักประเมินราคา | โต๊ะประเมินของ | ซื้อขายของได้กำไรมากขึ้น |
| 🦅 หน่วยข่าว | โต๊ะจับกลุ่มปาร์ตี้ | รู้ข่าวมอนบุกและบอสโลกล่วงหน้า ศัตรูอ่อนลง |
| 🍺 บาร์เทนเดอร์ | บาร์ | เครื่องดื่มขายได้มากขึ้น อารมณ์ดีขึ้น |
| 🍲 แม่ครัว | เตาทำอาหาร | อาหารฟื้นแรงมากขึ้น ขายได้มากขึ้น |

## เมือง

เมนู “หมู่บ้าน” สร้างและขยายอาคารได้ดังนี้:

| หมวด | อาคาร |
|---|---|
| ที่พักและรักษา | บ้านใหม่ โรงเตี๊ยม คลินิก |
| ค้าขาย | ร้านค้า ตลาดนัด โรงตีเหล็ก |
| ฝึกและสอบ | โรงฝึก สนามสอบ |
| แปรรูป | โรงฟอกหนัง โรงปรุงยา ร้านเจียระไน |
| การค้าระยะไกล | ลานคาราวาน โรงประมูล |
| เทศกาลและเกียรติยศ | ลานเทศกาล เวทีโคมไฟ อนุสาวรีย์วีรชน |

- **บ้าน:** โตเองเมื่อมีสิ่งที่ครอบครัวต้องการอยู่ใกล้ ทางเดินเกิดเองจากรอยเท้าและกลายเป็นถนน
- **ความพึงพอใจของชาวเมือง:** มาจากอาหาร ความปลอดภัย บ้านที่มีของครบ ที่เที่ยว งานที่กิลด์ช่วย และรอยแผลจากมอนบุก
  - พอใจ: ครอบครัวย้ายเข้า
  - ไม่พอใจนาน ๆ: ครอบครัวย้ายออก
- **แถบตัวเลขเหนือแถบเมนู:** 👥 ชาวเมือง · ⚔ นักผจญภัย · 😊 ความพึงพอใจ · 💰 รายได้ต่อวัน แตะเพื่อดูความต้องการเทียบกับความจุ ส่วนที่ขาดเป็นสีแดงพร้อมวิธีแก้
- **เมือง 5 ระดับ:** เห็นบนแผนที่ ระดับ 3 มีโคมไฟถนน ระดับ 4 มีประตูเมือง ระดับ 5 มีธงประดับ
- **ข้อควรระวัง:** เมืองยิ่งใหญ่ มอนบุกยิ่งเป็นฝูงใหญ่

## การค้า

- **รับซื้อชิ้นส่วน:** นักผจญภัยที่กลับจากล่ามอนขายชิ้นส่วนให้เคาน์เตอร์กิลด์ ตั้งราคารับซื้อได้ 3 แบบ
- **แปรรูป:** โรงแปรรูปเปลี่ยนชิ้นส่วน 3 ชิ้นเป็นสินค้าที่ราคาดีกว่า
- **ขาย:** ขายส่งให้พ่อค้า หรือส่งคาราวานไปเมืองหลวงเพื่อได้ราคาสูงกว่า
- **สมบัติ:** วางโชว์ ขายให้นักสะสม หรือส่งเข้าโรงประมูล

## เทศกาล

หัวหน้ากิลด์ตั้งเงินรางวัลและของรางวัลเอง ยิ่งรางวัลสูง คนยิ่งมาเยอะ

- **⚔ งานประลองยุทธ (สนามสอบ):**
  - นักผจญภัยสมัครลงแข่งเอง คนเก่งที่สุดที่ว่างและอารมณ์ดีสมัครก่อน
  - รางวัลยิ่งสูงยิ่งสมัครหลายคน สูงสุด 4 คน และดึงคนดังต่างเมืองมาแข่งด้วย
  - ถ้าคนของเมืองชนะ เงินรางวัลเข้ากระเป๋าเขา และของรางวัลกลับคลังกิลด์
- **🌾 เทศกาลเก็บเกี่ยว (ลานเทศกาล):** ความรุ่งเรืองของหมู่บ้านและครอบครัวใหม่
- **🏮 เทศกาลโคมลอย (เวทีโคมไฟ):** อารมณ์และความผูกพันของนักผจญภัย

## รางวัลและของสะสม

- **เป้าหมายวันนี้:** ทุกเช้ามี 3 ข้อ สำเร็จข้อละหนึ่งหีบไม้ ครบทั้ง 3 ข้อได้หีบเงิน
- **หีบ:** หีบไม้ หีบเงิน หีบทอง เปิดแล้วลุ้นได้ 4 ระดับ คือธรรมดา หายาก ล้ำค่า และตำนาน ระดับสูงอาจมีสมบัติ
- **สมุดภาพมอน (เมนู “กิลด์” → สมุดภาพมอน):**
  - ปราบชนิดใหม่ครั้งแรกได้โบนัส
  - บันทึกครบหน้าได้หีบเงิน
  - บางชนิดเจอเฉพาะในคำร้องของหมู่บ้าน
- **ชุดสมบัติ 3 ชุด:** สมบัติที่เคยเข้ามือกิลด์นับแล้ว ครบชุดได้เงิน ชื่อเสียง และหีบทอง
- **นโยบายกิลด์:** ทุกครั้งที่กิลด์เลื่อนระดับได้หีบทองและเลือกนโยบาย 1 ใน 3 ใบ นโยบายอยู่ถาวรและซ้อนกันได้ มีทั้งหมด 10 แบบ:

| นโยบาย | ผล |
|---|---|
| 💰 นายหน้ามือทอง | ค่านายหน้า +12% |
| 🚪 ประตูเปิดกว้าง | คนมาลงทะเบียนถี่ขึ้น 30% |
| 🍺 โรงเตี๊ยมคึกคัก | ราคาเครื่องดื่มและอาหาร +25% |
| 🩹 หมอประจำกิลด์ | บาดแผลหายเร็วขึ้น 40% |
| 🎯 ครูฝึกเข้มงวด | XP +15% |
| 📣 ชื่อเสียงขจรไกล | ชื่อเสียงจากงาน +20% |
| 🔨 ช่างประจำกิลด์ | ค่าอัปเกรดของใช้ −15% |
| 🔎 ตาไวของมีค่า | โอกาสพบสมบัติ ×2 |
| 💛 กิลด์อบอุ่น | อารมณ์ทุกคน +6 |
| ⚖ พ่อค้าเจ้าเสน่ห์ | ขายส่ง คาราวาน ประมูล +10% |

- **กลับมาเล่น:** หน้า “ระหว่างที่คุณไม่อยู่…” สรุปดอกผลและสิ่งที่รออยู่ ถ้าออกไปนานเกิน 10 นาทีมีหีบฝากไว้ที่ประตู

## เนื้อเรื่อง

- **บทที่ 1 · ป่าหมอกจันทร์:**
  - กิลด์ F → E → D → C ระหว่างทางมีจดหมายสอบจากสมาคมเป็นคำร้องสำคัญ
  - จบที่การรักษาหัวใจป่า ซึ่งเป็นการสอบเลื่อนเป็นกิลด์ B ด้วย
- **บทที่ 2 · ชายแดนตะวันออก:**
  - เปิดหุบผาลมแดง ตั้งค่ายแนวหน้า และปราบหนอนทรายยักษ์
  - ภารกิจจู่โจมแม่พญาไวเวิร์น และบทสุดท้ายราชันมังกรเพลิง
  - ภารกิจจู่โจมรับได้ถึง 6 คน ต้องมีค่ายแนวหน้าระดับ 2

คำร้องสำคัญก็ขึ้นกระดานเหมือนงานอื่น ทีมที่พร้อมจะหยิบไปเอง ถ้าไม่มีใครรับ กระดานจะบอกว่าขาดอะไร

## โหมดหัวหน้ากิลด์ (⚔)

กดปุ่ม ⚔ เพื่อออกไปเดินในโลกเอง:

| การกระทำ | คีย์บอร์ด |
|---|---|
| เดิน | WASD หรือลูกศร |
| ฟัน | J หรือ Space |
| ฟันหมุน | K |
| หลบ | L หรือ Shift |

บนมือถือใช้จอยสัมผัสและปุ่มบนจอ ของที่หัวหน้ากิลด์ได้เข้ากิลด์ตรง ๆ ถ้าสลบ ชาวบ้านจะหามกลับมา

## เคล็ดลับ

1. วางกระดานคำร้องให้เร็วที่สุด ทุกอย่างเริ่มจากงาน
2. ขยายที่พักก่อนที่คนจะมาไม่ได้ ดูได้จากเมนู “นักผจญภัย”
3. บาร์คือรายได้ข้างและยาแก้อารมณ์ที่ถูกที่สุด
4. เปิดหน้า “ประสิทธิภาพ” ทุกวัน แก้คอขวดที่เสียเงินมากที่สุดก่อน
5. ใช้ค่าหัวเฉพาะงานที่อยากให้เสร็จจริง เช่น คำร้องสำคัญและงานที่ค้างนาน
