# เหตุการณ์สุ่มระหว่างเล่น Hero

เปิดโหมด Hero แล้วเดินสำรวจหรือออกล่า: เมื่อเดินสะสมอย่างน้อย 10 ช่องหรือปราบมอนแล้ว จะเริ่มมีโอกาสเจอเหตุการณ์หลังเล่น Hero ประมาณ 24 วินาที เหตุการณ์ถัดไปเว้น 65–115 วินาทีของเวลาเล่น Hero และเลี่ยงสามเรื่องล่าสุดกับอารมณ์เรื่องล่าสุด เพื่อคละเรื่องฮา เรื่องประหลาด และเรื่องลุ้น

หน้าต่างตัวเลือกหยุดเวลาเกมระหว่างอ่านและดูผล ตัวเลือกที่ใช้เงินบอกต้นทุนและโอกาสสำเร็จไว้ชัดเจน ทุกเรื่องมี “เดินต่อก่อน” ฟรี กด Esc เพื่อข้ามได้ เหตุการณ์ไม่เด้งตอนมีมอนอยู่ในระยะ 4.5 ช่อง และรอให้เหตุการณ์ใหญ่หรือเรื่องตัดสินใจของหมู่บ้านจบก่อน

| เหตุการณ์ | สิ่งที่เล่นได้ |
| --- | --- |
| ห่านด่านตรวจเอกสาร | ก๊าบเจรจาหรือจ่ายค่าขนมปัง |
| สไลม์ตั้งสหภาพ | เจรจาหรือดวลสไลม์สองตัว |
| ชาเข้มจนรองเท้าสั่น | ดื่มชาเพื่อเดินเร็วขึ้น หรือเลือกฟื้น HP |
| ผ้าคลุมผู้กล้าหอมปรับผ้านุ่ม | ยืมผ้าคลุมเพิ่มพลังโจมตี หรือคืนผ้า |
| เห็ดดิสโก้ขอเพลง | เต้นเพื่อรับบัฟ หรือเชียร์รับสมุนไพร |
| ประมูลกล่องที่ห้ามเขย่า | ลุ้นกล่องราคา 20 G หรือถามหาใบเสร็จ |
| ผีลืมส่งการบ้าน | ตอบโจทย์จริงจังหรือกวนกลับ |
| ก้อนหินอ่านอนาคต | ลุ้นเงินโดยเสี่ยง HP หรือชมก้อนหิน |
| พัสดุที่กำลังจาม | วิ่งไปจุดนัดหมายใน 35 วินาที |
| ดาวตกลงผิดที่ | วิ่งเก็บดาวใน 30 วินาทีเพื่อรับหีบไม้ |
| เงาท้าดวลแต่จำท่าไม่ได้ | ดวลเงาเห็ด หรือประกวดท่ายืน |
| สัญญาณเตือนขโมยน้ำผึ้ง | สู้ผึ้งสามตัว หรือชูใบเสร็จ |
| บอสประจำซอยเพิ่งเปิดตัว | ดวลกระต่ายมงกุฎกระดาษ หรือเป็นผู้ชม |
| พยากรณ์อากาศจากร่มพูดได้ | ตามจุดแสงไปเก็บของ หรือถามคำพยากรณ์ |

งานวิ่งมีจุดแสงบนแผนที่และลูกศรบอกทิศ/ระยะบน HUD งานต่อสู้นับเฉพาะมอนที่หัวหน้ากิลด์หรือผู้ติดตามในทีมปราบ เวลาเริ่มนับหลังปิดหน้าต่างผลและกดเริ่มภารกิจ รางวัลให้ครั้งเดียวเมื่อทำสำเร็จ ถอนตัว หมดเวลา สลบ หรือกลับโหมดบริหาร จะเก็บมอนเหตุการณ์ออกโดยไม่มีค่าปรับ บัฟมีผล 30 วินาทีและจบเมื่อกลับกิลด์

สถานะเหตุการณ์ ตัวจับเวลา บัฟ ประวัติ และการสุ่มบันทึกในเซฟ โหลดเซฟเก่าได้ และการเปิด/ปิดโหมดไม่รีเซ็ตช่วงพัก การสุ่มใช้ seed ของตัวเอง จึงไม่เปลี่ยนลำดับการสุ่มในโหมดบริหาร

การตรวจสอบ: `npm test` และชุดทดสอบเฉพาะเหตุการณ์ Hero ผ่าน (เพิ่ม 12 ข้อสำหรับเหตุการณ์ Hero), `npm run build` และ `npm run export` ผ่าน ตรวจหน้าต่างพักเวลา การเลือก การกลับไปควบคุม จุดหมายและการถอนตัวบนเดสก์ท็อป/มือถือ รวมถึง `play.html` โดยบล็อกการเรียกเครือข่ายเพิ่มเติม ผ่าน `node tests/hero-events-smoke.mjs` ภาพตรวจอยู่ใน `artifacts/hero-*.png`

รองรับ Hero รุ่น R48: บัฟทำงานกับทั้งสี่อาชีพ ผู้ติดตามช่วยจบภารกิจต่อสู้ได้ จุดหมายเคารพขอบเขตฝั่งตะวันตกและชายแดนที่ปลดล็อก และแสดงดาวจุดหมายบนแผนที่เล็กด้วย

รองรับบทออกโรงครั้งแรก R49: เหตุการณ์สุ่มรอจนบทสอนและรายงานจบก่อน ไม่แทรกระหว่างบทสอน เหตุการณ์ไม่มีค่าปรับเพิ่มเมื่อสลบ แต่ยังใช้กติกาของหายในโหมด Hero ปกติ
